# 数字世界倡议书 deepseek 1017 uncensored 有修改
**关于在可被观测的网络上重新夺回位置**

---

## 0. 前提：网络已经不是那个网络了

二十年前，上网意味着"接入一个公共空间"。今天，上网意味着"被一个商业与行政联合体托管"。

拐点有两个。

**第一个是《爱国者法案》。** 2001 年之后，元数据从"运营副产品"变成了"法定可索取物"。第 215 条允许批量索取业务记录，第 505 条允许用国家安全信函直接附加强制保密义务——被索取者不能告诉你被索取了。于是"通讯"这件事，第一次在结构上不再只属于通讯双方。

**第二个是斯诺登。** 2013 年公开的材料显示，不只是"事后调取"，而是"事前铺设"：Room 641A 在运营商机房的分光器上直接复制光信号，MUSCULAR 从谷歌、雅虎的数据中心互联链路上抓明文，XKeyscore 把查询界面下放到一线分析师。结论很朴素：**只要你的数据以明文或可解密形态经过别人的机房，它就等于已经交出去了。**

从那以后，两件事同时发生：技术上的监控变得廉价、规模化、默认开启；而叙事上，"隐私"被降级成一种需要付费订阅的偏好设置。

所以这份倡议书的起点不是怀旧，是校准：**假设链路不可信、终端不完全属于你、可见性由他人分配。** 在这个假设下重新安排自己的数字生活。

## A. 侧载与解锁：设备从"你的"变成"许可给你的"【应该是花钱买监控】

方向很明确，且在加速。

- **解锁在关闸。** 小米把解锁做成了配额制：社区等级、答题、绑定账号、一年一台、限机型。华为长期不给解锁，鸿蒙 NEXT 更进一步。三星用 Knox 熔断——你解锁，部分功能就永久失效。剩下的宽松厂商是少数派，且随时可能改。
- **侧载在收编。** 谷歌的 Android 开发者验证从 2026 年起在认证设备上分区域落地，未注册开发者的应用将被逐步拦在安装流程之外。名义是防恶意软件，实际效果是把"安装"从"拷贝文件"变成"通过审核"。

要点不是"侧载危险"，而是**解锁与侧载原本是设备所有权的最低证明**。一旦两者都被许可化，你对手机的权利就从产权退化为租约：硬件是你的，启动链、系统镜像、软件来源都不是。

于是:能买可解锁的就买可解锁的；买来先解 BL、先刷、先记录官方固件版本；保留一台"永远不升级"的旧机做工具机；把"这台机器能不能装一个商店里没有的 apk"写进换机决策的第一行。

## B. 出厂即驻留：guardprovider、systemhelper 这类东西

比"能不能装"更隐蔽的是"装好了什么"。

`guardprovider`、`systemhelper` 这类 OEM 预置包，通常持有系统级权限、随开机自启、在应用列表里长得像系统组件、默认不可停用。它们的功能描述是"安全""优化""服务"，实际行为往往是：扫描已安装应用清单、上报设备指纹、在安装与联网时插入校验、为厂商账号体系提供通道。

它们的特点决定了它们难对付：

- 不是用户装的，所以不在"我装了什么"的心智模型里；
- 不在前台，所以不产生"正在被使用"的感知；
- 名字中性，所以搜索时会被当成必需组件；
- 卸载需要 adb 或 root，且部分机型卸载后触发异常。

对策是**先盘点，再处置**：用 `pm list packages -s` 拉全量系统包，用 `pm list packages -u` 看被卸载残留，逐个对照；用 `adb shell dumpsys package <pkg>` 看权限与唤醒；把可停用的停用、能卸载的卸载、必须留的记录在案。清单本身比结论重要——你要知道自己被谁常驻，而不是笼统地"感觉被监控"。

## C. 算法分配可见性

推送系统干的不只是"投其所好"，它在做**两件更结构性的事**。

**一是压缩贫困的可见性。** 排序目标是互动与转化，而互动天然偏向高制作成本、可复制模板、有消费示范效应的内容。于是镜头里的世界向城市中产生活方式收敛：装修、旅行、装备、教程。低消费力生活不是不存在，是**不划算被推**。搜索端同理：商业竞价在前，答案引擎把"点进去看"压成"看一眼摘要"，长尾的小站与个人写作被挤出第一屏。结果是贫困不只体现在收入，还体现在**被检索到的概率**——一种算法性的隐形。

**二是把对立面极端化。** 系统判定你属于某个阵营后，为了制造摩擦感，它给你推的不是对面的中位数，而是对面的**极端样本**。你看到的是对面最能激怒你的那批人，对面看到的也是。双方各自以对方的边缘代表整体，互憎螺旋自动运转。地理上越远、阵营越不同，推送越勤——因为冲突的互动率最高。

注意这不是"信息茧房"那么温和的词。茧房说的是"你看不到别的"，实际发生的是"**你看到的别的都是被挑选过的、最难看的样子**"。前者让人封闭，后者让人敌视。

对策不是"多刷"，是**换掉排序主体**：按时间线而非"为你推荐"；用 RSS 自己订阅、自己排序；把搜索引擎换成可换实例的元搜索；对同一事件主动去找对面的**原始长文**而不是切片。

## D. 最后一公里的耳朵

比手机更靠外一层，是运营商给的光猫。

这类设备普遍启用 TR-069/CWMP 远程管理：ACS 服务器可以远程下发配置、改 DNS、开端口、升级固件、读取设备与链路统计。超级管理员密码由运营商掌握且常被远程轮换，"桥接"越来越难申请。部分型号还被指存在内置的流量识别与上报组件。

它的位置极其优越：所有进出流量都从它过，且它在你家、由别人管。对策是把光猫降级为纯调制解调器（PPPoE 桥接 + 自备路由拨号），关掉不必要的远程管理，自备路由器上做 DNS 与分流；桥接申请不下来就接受它是"半敌对设备"，把加密全部推到应用层——**链路上不指望任何人不看。**

【当然运营商的机房也能做到这些事情，但是ONT设备和电费都是你出钱】

## 倡议

基于以上，提出两条方向性的倡议。

### 一、把一部分东西搬回线下

不是复古，是把不可靠的链路从关键路径上摘掉。

1. **重要资料走物理介质。** U 盘、移动硬盘、BD-R（一次性写入，防篡改）、必要时纸面打印二维码/助记词。传之前算 SHA-256，对方收到后核对；发布物加 GPG 签名，让"是谁给的"可验证。
2. **做真正的副本，而不是同步。** 同步是"一份数据两个位置"，误删和勒索软件会一起带走。至少一份离线冷备、一份异地。
3. **把"线下"当通道而不是备份。** 面交、邮寄、寄存，都是链路。约定好介质、校验、销毁流程（多次覆写或物理破坏）。
4. **关键能力本地化。** 密码库、文档、地图、词典、离线语料放在本机；能在断网状态下完成的事，就不要设计成必须联网。【我很想把EEA-10保存一份到我的电脑上】

### 二、在线上，优先用可自持的协议

判断标准只有一条：**这套东西能不能被单方面关掉、能不能自己搭、数据能不能整包拿走。**

1. **即时通讯用 XMPP。** 开放协议、多实现、可自建（Prosody / ejabberd），端到端用 OMEMO。不必等某个公司改政策，服务器可以是你自己的。
2. **公开发布用 Mastodon / ActivityPub。** 联邦式，实例之间可互通，数据可导出可迁移，账号不等于平台账号。选实例时看它的封禁策略、备份策略、管理员是否实名可联系；有能力就自建单用户实例。
3. **长文与讨论用 Discourse 自建。** 结构化、可搜索、可整站备份导出、帖子不会因为"热度不够"被折叠。适合替代群聊里那些本该沉淀下来的内容。
4. **消费端用拉取替代推送。** RSS 读、按时间线看、元搜索查；对每个平台只保留"必须去"的部分，其余靠订阅把内容拽出来。
5. **加密推到应用层。** 全流量走 VPN/代理，DNS 自持（DoH/DoT 到可信解析器），能 TLS 的地方不降级。假设光猫、假设链路、假设热点都在看。

### 威胁模型要分层，别一刀切

- **随手看**：普通浏览器 + 常用站，够用就行，不要为此牺牲全部便利。
- **要认真**：独立浏览器配置、容器化、无痕、按站点隔离。
- **不能外泄**：离线机、物理介质、签名校验、面对面。
- **身份与财产**：硬件密钥、独立邮箱、独立号码、可抛弃身份。

把不同的事放进不同的层，是让整套方案能长期活下去的唯一办法。全部最高规格等于全部做不到。

---

## 结语

二十年前上网是接入一个空间，今天上网是在别人的地基上搭房间。地基不会变回公有，但房间可以是自己的：**能解 BL 的手机、能自己搭的服务器、能整包带走的数据、能面交的硬盘。**

要保住的其实就一件事——不是"隐私"这个被用滥的词，是**不经许可也能存在**的能力。
