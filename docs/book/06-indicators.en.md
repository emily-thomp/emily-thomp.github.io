# Technical and economic indicators

The book lists the following performance figures:

| Indicator | Original value |
| --- | --- |
| Ammonia oxidation efficiency | 85–90% |
| Absorption efficiency | 90% |
| Overall ammonia utilization | 76% |
| Liquid ammonia per tonne of 100% nitric acid | 357 kg |
| Electricity consumption per tonne of 100% nitric acid | 160 kilowatts, as printed |
| Catalyst consumption per tonne of 100% nitric acid | Approximately 0.2 kg |

> Editorial note: the original gives electricity consumption in “kilowatts,” rather than an energy unit. The printed unit is retained without silently substituting kWh.
