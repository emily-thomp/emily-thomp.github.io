# 安全技术与劳动保护

## 六、 安全技术与劳动保护注意事项

1.氨氧化时，氨的濃度不能超过12%，否则，将会引起爆炸危险，另一方面，氨濃度过高，将会导致轉化率的下降。

2.用氢焰点火时，应先用氢气排气，以免点火时氢与空气混合气爆炸。在触媒点火时或加温时，操作人员应戴防护眼镜及防氨口罩。如无防氨口罩时，可以用湿毛巾将口鼻扎住，防止氨的突然冲出，使操作人员悶倒。最好在点火时，氨氧化炉的负压保持较大，则可避免氨的冲出。在开氨气閥应小心調节，不能开得太大。

3.触媒的温度不能高过820℃，温度过高，就会使触媒损坏。

4.吸收系統操作时，应戴防护眼镜，以免酸液溅入眼内。

5.在灌装硝酸时，应戴橡胶手套，以免硝酸的灼伤。万一不慎而被硝酸溅着，应立即用清水冲洗或用稀碱水洗滌后，再用清水清洗。

6.灌装液氨时，应防止接管的漏气，以免钢瓶中液氨冲出。在使用时，当鋼瓶与稳压器接通后,略为将氨瓶上的閥门开启少許，如无漏气现象时，才能开大。

7.存放液氨的鋼瓶不能曝晒在日光下，以免温度过高，氨瓶压力增大，发生爆炸危险。
