# 生产系统的开停车

## II 生产操作及生产控制

## 一、 生产系统的开停车

## （1） 开车前的准备工作：

1. 检查各处管路接合处是否严密。要求气体管道及液体管道不漏气体及液体，如果，发现有漏的地方，必须加以密封。

2. 检查鼓风机及酸泵等动力设备系统送电是否正常。输电线路应防止被酸液浸触而发生漏电或触电等危险。

3. 所装温度计及流量计等须加以检查是否有失灵现象，以免控制困难。

4. 开车前先将氨瓶接至稳压器，使其有一定量的存氨(可看压力磅表，使其保持在4公斤/厘米²)。待开车使用时，再蒸发氨瓶内的液氨。

(2)开车步骤：

1. 在吸收塔部分，先将酸液循环泵开启，使塔内有液体循环。同时检查酸泵轧兰有否漏液现象。因木制泵浦轧兰填衬容易漏液，所以必须经常注意。

2. 开动鼓风机，先送入少量的空气（约开10立方米的空气流量)到整个生产系统中。为了使触媒点火的方便，最好能送入预热的空气。加热的方法，可以在出流量计后的空气管道上用煤在外壁加热，使其达到200~250℃。

3. 氨接触反应器内的温度；上升至150～200℃左右时，将接触器上部的点火孔（平时用作视孔）打开，用氢气火焰加热点火。在触媒上点火时，触媒的温度逐渐上升，当热电偶上的指示温度上升至300~350℃时，将氨气逐渐通入。如果点火时，温度计上升缓慢，可以略为开些氨气，使其发生反应而促使温度上升得快些。在点火时，氨接触器应保持一定负压(可以在接触器的出口管道上接一支路用排风机抽气，使其达到负压。如果有蒸气供应的话，可以装一个蒸气喷射抽气装置，用蒸气喷射，使其抽成负压)，这样，可以使氢焰穿入触媒层中间，升温较快，点火工作大约在10～15分钟即能点好。如果,在正压较大的情况下点火，氢焰会在触媒层上面燃烧，有时火焰会在点火孔处向外冲出，或则会导致氨气的燃烧，这一点应该特别注意。在点火时，氨的浓度应保持在10.5%左右，这样，触媒表面很容易呈暗红色，那就表示开始反应了，这个时候点火工作即可停止。如果氨的浓度较低，点火时触媒的表面虽呈红色，但当氢焰取出后，有时反应也会停止进行，而触媒表面的红色也消失了，触媒层温度也就下降，因此氨全部就不起反应了。当触媒层温度达到正常，一般是在700～800℃左右，将氨浓度调节至10～10.5%，预热空气的温度也调节至200℃左右。如果氨的浓度较低，则应将预热空气温度提高。在正常操作时，应经常注意触媒层表面的颜色，呈红色就表示反应在正常的情况下进行。如果，由于控制不当，触媒表面红色衰退呈暗色，而热电偶温度有很快的上升时,这就表示触媒表面没有起氧化反应,而起分解反应，氧化率就会下降，应加防止。

如果用一层铂网与铁铋触媒结合使用时，则须注意防止点火杆将铂网拉破。

4. 点火工作完毕后，可以观察触媒层温度逐渐上升，待温度达到正常时(用非铂触媒，温度在700~750℃左右，如用一层铂网与非铂触媒结合使用，温度在750℃)，即可逐步地将氨及空气的流量开大至规定量。在开大流量时，须先开大空气，然后再开氨气，二者相应地开高，切不可单开氨气。否则，会造成氨的浓度过高而发生故障。

5. 一切正常后，就可以将空气调换至热交换器中，利用反应的热量加热空气。

(3)停车步骤:

1. 停车时，先将氨气阀门关闭，停止送入氨气，这时，由于停止送入氨气，反应也随着停止。

2. 在15分钟后，将空气鼓风机停止运转，并关闭空气阀门。

3. 再待10分钟后，停止酸液循环，并将酸泵的进出阀门关闭，将酸泵停掉。

4. 如停车的时间比较长，那末，应该在停车前，先将氨蒸发停止，并将所存的气体用完，然后停车。
