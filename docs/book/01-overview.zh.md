# 概述与书籍信息

## 氨氧化土法制硝酸

吴亚义 编

科技卫生出版社

内 容 提 要

本书重点介绍了由氨的接触氧化，利用土设备来制取硝酸。内容有土法制硝酸的生产流程，单件设备的构造简图、材料和其作用说明，生产操作和控制，分析方法及接触剂制造等。

本书可作为各使用硝酸原料的工厂企业自搞土法硝酸生产时参考，也可供土法制造硝酸操作人员阅读。

## 序言

硝酸的生产可以用浓硫酸及硝石（硝酸钠）蒸馏制取，虽然设备简单，操作方法容易，但是由于浓硫酸及硝酸钠的供应还是不能满足其他工业的需要,因此,采用此法制硝酸在推广应用上存在一定的困难。本书内容主要介绍用土设备以氨氧化方法制取硝酸，在接触剂方面以铁铋氧化物作触媒；代替目前国内还不能供应的铂铑网，以陶器等代替不锈钢制吸收塔，所用设备材料大部分都能自制，而小部分材料如仪表等市场上亦有供应，因此，建厂容易，投资费用也很低。为了便于使用硝酸的厂矿企业自己生产硝酸起见，今将土法生产硝酸的流程及单体设备的构造作用，生产操作控制以及触媒的制造方法等汇编在一起，俾供各单位参考。

本书的资料大部分是根据上海化工研究院及上海天工酸碱厂等土法硝酸生产的实际情况，同时也参考了1955年日本产业图书株式会社出版的内田信一等著：“硝酸”及1954年商务印书馆出版的周家镛著:“硝酸工学”等书上的材料编写的。由于作者对硝酸的生产经验不足，编写时间短促，内容方面可能有许多错误不详之处,希望读者多加批评指正！

## 概述

硝酸是一种重要的化工产品。在各种酸类中，它的规模仅次于硫酸。硝酸和硝酸盐类在国民经济中具有极其重大的意义。硝酸主要用在农业和国防工业上，象硝酸与氨中和后制成的硝酸铵是一种良好的肥料，含氮量有35%，施肥后，它的氮素能很快的被植物所吸收，对棉花，亚麻，烟草和蔬菜等有很好的肥效。硝酸铵有很大一部分用于制造无烟火药或混合炸药，作为兴修水利，开矿等用，这些都是需要用大量硝酸作为原料。

硝酸亦可制造照相用的药剂和医药用的药剂。染料制造工业上亦需用大量的硝酸作为原料制成各种有机性染料。在制造硫酸的过程中也有用硝酸作为接触剂，使二氧化硫氧化成三氧化硫，然后被水吸收制成硫酸。

随着工农业大跃进形势不断的高涨，各方面对硝酸的需要量也不断的增长了。我国在短短的几年内已经扩建和新建了许多大型的硝酸工厂，但是在工农业生产飞跃前进的形势下，硝酸的产量还跟不上形势的发展。

由于硝酸工业生产上需要大量的不锈钢材与铂合金网的设备，也就限制了硝酸制造工业的普遍发展。一般人们认为硝酸生产不能采用土法，遍地开花。但在党中央提出了大搞小型土法，一切为钢铁元帅服务的口号鼓舞下，我们打破了迷信，解放了思想，终于在短短的时间内，采用土法生产出了硝酸，并已在逐步推广中。下面主要介绍小型土设备，利用氨氧化法制硝酸的生产流程.操作事项以及分析方法等，供各地搞土法硝酸的同志们参考。
